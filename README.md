# TacticalAnalysis — Football Highlighter

축구 영상에서 선수를 자동으로 추적하고, 방송 전술 분석 스타일의 그래픽(빛기둥 · 발밑 링 ·
이름표 · 대형선 · 구역 표시 · 자막 · 정지 카드)을 입혀 하이라이트 영상으로 내보내는
**macOS 데스크톱 편집기**입니다.

> A macOS desktop editor that tracks players in football footage (YOLO11 + BoT-SORT) and
> overlays broadcast-style tactical graphics — player pillars, formation lines, zones,
> captions and freeze frames — then exports a finished highlight video. UI is in Korean.

## 주요 기능

| 기능 | 설명 |
|---|---|
| **자동 선수 추적** | YOLO11 탐지 + 튜닝한 BoT-SORT 추적. 카메라 팬/줌 보정, 끊긴 조각 자동 잇기, 샷 전환 감지 |
| **팀 자동 구분** | 유니폼 색으로 두 팀을 나누고, 상대 팀 선수에게 번호가 넘어가는 추적 오류를 자동으로 자름 |
| **추적 보정 도구** | 합치기 · 맞바꾸기 · 끊기 · 팀 지정. 모두 되돌릴 수 있는 보정 기록으로 저장 |
| **선수 강조** | 유리관 빛기둥 · 발밑 원판 · HUD 링 · 말풍선 이름표. 부드러운 등장/퇴장 애니메이션 |
| **대형선** | 클릭한 순서대로 수비 · 미드 · 공격 라인을 잇기 (끄고 강조만 하는 것도 가능) |
| **구역 표시** | 화면 어디든 잔디에 눕힌 타원으로 공간 · 패스 경로 짚기 |
| **자막 · 정지 카드** | 6가지 등장 효과의 자막, 영상을 멈추고 그 위에서 그래픽을 보여 주는 정지 구간 |
| **타임라인 편집** | 결과 영상 시간 기준 타임라인. 막대를 끌어 표시 구간 편집, ⌘-클릭으로 여러 줄 함께 편집 |
| **여러 클립 이어 붙이기** | 클립 여러 개를 일괄 분석하고, 해상도 · fps가 달라도 한 영상으로 내보내기 |
| **프로젝트 저장** | 추적 결과와 모든 편집 내용을 `.fbproj` 파일 하나로 저장 · 다시 열기 |

모든 처리는 **내 컴퓨터 안에서** 이루어집니다. 영상을 어디에도 업로드하지 않습니다.

## 시스템 요구 사항

|  | 최소 | 권장 |
|---|---|---|
| **운영체제** | macOS 13 Ventura | macOS 14 이상 (macOS 26에서 테스트) |
| **프로세서** | Intel Mac (CPU 분석 — 매우 느림) | **Apple Silicon (M1 이상)** — GPU(MPS) 가속 |
| **메모리** | 8 GB | 16 GB 이상 |
| **저장 공간** | 3 GB 여유 (가상환경 약 1 GB + 모델 가중치 + 작업 영상) | 10 GB 이상 |
| **Python** | 3.11 ~ 3.13 (python.org 또는 Homebrew) | **3.13** (python.org 설치본) |
| **네트워크** | 첫 설치 · 첫 분석 때만 필요 (패키지, 모델 가중치 다운로드) | |

- **Windows · Linux는 공식 지원하지 않습니다.** 한글 폰트 경로와 단축키가 macOS 기준입니다.
- **Anaconda Python은 지원하지 않습니다.** Qt 창이 뜨지 않습니다([문제 해결](#문제-해결) 참고).
- 분석 속도 참고치 (Apple M2, 1280×658 중계 영상): 기본 프리셋 **약 20 fps** — 30초 클립을 1분 안에 분석합니다.
  NVIDIA GPU가 있으면 CUDA를 자동으로 씁니다.

## 설치

### 1. Python 설치

[python.org](https://www.python.org/downloads/macos/)에서 **Python 3.13** macOS 설치 파일을 받아 설치합니다.
Homebrew를 쓴다면 `brew install python@3.13` 도 됩니다.

### 2. 저장소 받기

```bash
git clone https://github.com/dydwls2227/TacticalAnalysis.git
```

```bash
cd TacticalAnalysis
```

Git이 없다면 GitHub 페이지의 **Code → Download ZIP** 으로 받아 압축을 풀어도 됩니다.

### 3. 첫 실행 (자동 설치)

```bash
./run.sh
```

처음 실행하면 가상환경을 만들고 의존성(PyTorch, Ultralytics, PySide6 등)을 설치합니다.
네트워크 속도에 따라 **3 ~ 10분** 걸립니다. 다음부터는 바로 실행됩니다.

> `permission denied` 가 나오면 `chmod +x run.sh` 후 다시 실행하세요.

### 설치되는 위치

| 무엇 | 위치 | 크기 |
|---|---|---|
| 가상환경 | `~/.venvs/tactical-analysis` (`FBEDIT_VENV` 로 변경 가능) | 약 1 GB |
| YOLO 모델 가중치 | `~/.cache/football-highlighter/models` (첫 분석 때 자동 다운로드) | 20 ~ 110 MB |
| 폰트 목록 캐시 | `~/.cache/football-highlighter/fonts.json` | 수 KB |

가상환경을 프로젝트 폴더 밖에 두는 이유: 프로젝트를 iCloud가 동기화하는 `~/Desktop`,
`~/Documents` 에 두면 macOS의 "Mac 저장 공간 최적화"가 큰 파일을 클라우드로 내보내,
앱이 그 파일을 읽는 순간 응답 없이 멈출 수 있습니다.

### 삭제

```bash
rm -rf ~/.venvs/tactical-analysis ~/.cache/football-highlighter
```

그다음 저장소 폴더를 지우면 완전히 제거됩니다.

## 실행

| 명령 | 동작 |
|---|---|
| `./run.sh` | 앱 실행 |
| `./run.sh 영상.mp4` | 영상을 열면서 실행 |
| `./run.sh 작업.fbproj` | 저장한 프로젝트를 열면서 실행 |
| `./run.sh --setup` | 가상환경을 처음부터 다시 만들기 (업데이트 후 오류가 날 때) |

| 환경변수 | 용도 |
|---|---|
| `FBEDIT_VENV` | 가상환경 위치 지정 |
| `FBEDIT_PYTHON` | 가상환경을 만들 Python 지정 (예: `FBEDIT_PYTHON=/opt/homebrew/bin/python3.12 ./run.sh --setup`) |

**업데이트:** `git pull` 한 뒤 `requirements.txt` 가 바뀌었다면 `./run.sh --setup`.

지원 영상 형식: MP4 · MOV · MKV · AVI 등 FFmpeg/OpenCV가 읽는 대부분의 형식.
**10 ~ 30초 클립**을 권장합니다.

## 빠른 시작

1. 영상 파일을 창에 **끌어다 놓습니다** (또는 ⌘O).
2. **분석** (⌘R) — 끝나면 자동으로 선수 강조 도구가 켜집니다.
3. 영상에서 **선수를 클릭**하면 그 프레임부터 강조됩니다. 우클릭하면 다음 라인(수비 → 미드 → 공격)으로 넘어갑니다.
4. **Space** 로 재생하며 애니메이션을 확인합니다.
5. **내보내기 ▾ → 이 클립** (⌘E).

## 사용 설명서

### 화면 구성

```
┌ 영상 추가 · 분석 ▾ · 내보내기 ▾ ── ① 영상 — ② 분석 — ③ 선수 강조 — ④ 내보내기 ── ↶ ↷ 💾 ┐
│ 클립 목록  │        영상  [ 선택 · 강조 · 구역 │ 라인 │ 자막 · 정지 ]         │  속성 패널   │
│ (썸네일)   │ ◀ ▶ ▶  00:12 / 01:30                                          │ (고른 항목에 │
│            │ 타임라인 — 선수 · 구역 · 자막 · 정지 카드가 한 줄씩 막대로       │  따라 바뀜)  │
└────────────────────────────────────────────────────────────────────────────────────────┘
```

- **단계 표시**(위 가운데): 지금 할 일을 알려 줍니다.
- **클립 목록**(왼쪽): 썸네일 오른쪽 위 점 — 초록 = 분석 완료, 회색 = 분석 전, 빨강 = 원본 없음.
  끌어서 순서를 바꾸면 이어 붙이는 순서가 바뀝니다.
- **속성 패널**(오른쪽): 아무것도 고르지 않으면 *클립 설정*(분석 구간, 강조 모양, 색, 애니메이션, 팀 구분)을,
  선수 · 구역 · 자막을 고르면 그 항목의 설정을 보여 줍니다.
- **타임라인**(아래): 강조한 선수, 구역, 자막, 정지 카드가 막대로 표시됩니다.

### 1. 분석

- 속성 패널의 **분석 구간**으로 필요한 부분만 분석하면 빠릅니다.
- 품질은 `분석 ▾` 메뉴에서 고릅니다.

| 프리셋 | 모델 | 속도 (M2) | 언제 |
|---|---|---|---|
| **빠름** (기본) | yolo11s · 960 | 약 20 fps | 대부분의 중계 화면 |
| 균형 | yolo11m · 1280 | 약 4 fps | 원거리 선수가 자주 놓칠 때 |
| 정밀 | yolo11x · 1280 | 약 1.3 fps | 아주 작은 선수까지 필요할 때 |

상위 프리셋은 탐지가 몇 % 늘지만 속도는 크게 느려집니다. 보통은 `빠름`으로 충분합니다.

### 2. 도구 — 영상 위에 떠 있는 막대

| 도구 | 키 | 영상에서 하는 일 |
|---|---|---|
| **선택** | V | 선수 · 구역을 골라 오른쪽에서 편집. 구역은 끌어서 옮김 |
| **선수 강조** | H | 클릭 = 이 프레임부터 강조 · 보이는 선수 다시 클릭 = 여기서 끝 · 우클릭 = 다음 라인 |
| **구역** | Z | 클릭한 자리에 구역 타원을 놓음 |
| 라인 잇기 | L | 강조한 선수를 대형선으로 이을지 켜고 끄기 |
| 자막 추가 | T | 현재 위치에 2초 자막 |
| 정지 카드 | F | 현재 위치에서 영상을 3초 멈춤 |

- 어느 도구에서든 선수를 **더블클릭**하면 등번호 · 이름 · 색 편집창이 열립니다.
- 마우스를 올리면 선수 테두리와 팀 색 점이 미리 보입니다.
- **Esc** 는 선택 도구로 돌아가거나 선택을 해제합니다.

### 3. 대형선

선수 강조 도구(H)에서 수비 4명을 차례로 클릭 → **우클릭** → 미드필더 클릭 → **우클릭** → 공격진 클릭.
라인은 **수비 → 미드 → 공격 → GK** 순으로 바뀌고, 선은 클릭한 순서대로 이어집니다.

- 선 없이 선수 몇 명만 강조하려면 **라인 잇기(L)** 를 끄세요. 설정은 다음 실행에도 유지됩니다.
- 한 라인에는 **한 팀만** 넣으세요. 다른 팀이 섞이면 상태 표시줄에 경고가 뜹니다.
- 라인은 나중에 속성 패널에서 바꿀 수 있습니다(최대 8개).

### 4. 타임라인 — 표시 구간 편집

타임라인의 가로축은 **결과 영상의 시간**입니다. 정지 카드가 있으면 그 길이만큼 빗금 블록이 들어가고,
뒤쪽은 자동으로 밀립니다.

| 조작 | 동작 |
|---|---|
| 막대 **양끝 끌기** | 시작 / 끝 변경 |
| 막대 **가운데 끌기** | 길이 유지한 채 이동 |
| 빈 곳 **더블클릭** | 1초 구간 추가 |
| 막대 **우클릭** | 그 구간 삭제 |
| 빈 곳 클릭 · 끌기 | 재생 위치 이동 |
| 왼쪽 **이름 클릭** | 그 항목을 고르고 그 장면으로 이동 |
| **⌘-클릭** (이름 또는 막대) | 여러 줄 함께 고르기 — 하나를 끌면 고른 막대가 모두 같은 만큼 늘고 줄고 이동 |

한 선수가 서로 떨어진 장면에서 여러 번 강조될 수 있도록 구간은 여러 개 가질 수 있습니다.
속성 패널의 `여기부터` / `여기까지` / `항상` 버튼으로도 편집하고, `강조한 모든 선수에 함께 적용` 을 켜면
열려 있는 구간을 한꺼번에 닫을 수 있습니다.

### 5. 강조 모양 · 색 · 애니메이션

- 아무것도 고르지 않은 상태의 속성 패널에서 **강조 모양**(빛기둥 · 발밑 빛 · 발밑 링 · 이름표)과 **기본 색**을 정합니다.
- 선수 한 명만 다른 색으로 하려면 그 선수를 고르고 색 견본을 누릅니다.
- **애니메이션**: 원판이 커지고 → 링과 파동 → 기둥이 솟아오르고 → 이름표가 떠오릅니다(약 0.5초).
  구간 끝에서는 0.3초 동안 옅어지며 내려앉습니다. 링 회전 · 기둥의 빛 흐름은 반복 효과입니다.
  속성 패널의 `애니메이션` 에서 등장·퇴장 / 반복 효과를 따로 끌 수 있습니다.
- 애니메이션은 **재생 중과 내보낸 영상**에서 보입니다. 멈춘 화면에서는 완성된 모습을 보여 줍니다.

### 6. 구역 표시

추적과 무관하게 화면 어디든 구역을 놓습니다(분석 전에도 가능).

1. 구역 도구(Z) → 영상 클릭
2. 끌어서 위치 조정, 속성 패널에서 이름 · 색 · 크기 · 진하기 · **원근**(눕힌 정도) · 테두리만
3. 표시 구간은 선수와 똑같이 타임라인에서 편집

### 7. 자막 · 정지 카드

| 항목 | 동작 |
|---|---|
| **자막** (T) | 영상이 흐르는 동안 지정한 구간에 자막 표시 |
| **정지 카드** (F) | 그 장면에서 영상을 멈추고 N초(기본 3초) 유지하며 자막 표시 |

- 글꼴 · 크기 · 위치 · 색 · 등장 효과(없음 / 페이드 / 아래에서 위로 / 팝 / 타자기 / 와이프)를 고릅니다.
- 정지 카드는 타임라인에 **실제 길이의 블록**으로 들어갑니다. 오른쪽 끝을 끌면 길이가, 가운데를 끌면 멈추는 장면이 바뀝니다.
- **정지 구간 안에서도 편집할 수 있습니다.** 재생 위치를 블록 안에 두고 구역을 놓거나 선수를 강조하면
  멈춘 화면 위에서 그 시점에 나타납니다. `정지 구간 재생` 으로 바로 확인하세요.
- 한글을 지원하는 시스템 폰트를 자동으로 찾아 목록에 올립니다(첫 실행 때 2 ~ 3초 스캔).

> **정지 카드를 넣으면 내보낸 영상에 오디오가 빠집니다.** 영상이 원본보다 길어져 소리가 어긋나기 때문입니다.

### 8. 팀 구분 · 추적 보정

분석할 때 유니폼 색으로 **팀 A / 팀 B / 기타**(심판 · 골키퍼 등)를 자동으로 나눕니다.
감지한 팀 색과 인원은 속성 패널의 `팀 구분` 에서 볼 수 있습니다.

선수가 겹치면 추적이 끊기거나 번호가 바뀔 수 있습니다. 선택 도구(V)로 선수를 고른 뒤 `팀 · 추적 보정` 에서 고칩니다.

| 증상 | 버튼 | 하는 일 |
|---|---|---|
| 끊겨서 **다른 번호**가 됐다 | `합치기…` → 그 조각 클릭 | 조각을 이 선수에 합침 (이름 · 강조 · 구간이 이어짐) |
| 둘이 엇갈리며 **번호가 뒤바뀌었다** | 바뀐 프레임에서 `여기서부터 맞바꾸기…` → 상대 클릭 | 지금부터 두 선수를 맞바꿈 |
| 추적이 **엉뚱한 선수로 넘어갔다** | 넘어간 프레임에서 `여기서 끊기` | 지금부터를 새 선수로 떼어냄 |
| 팀이 틀렸다 | `팀 A / 팀 B / 기타` | 직접 지정 |

`합치기` · `맞바꾸기` 는 버튼을 누른 뒤 다른 프레임으로 가서 클릭하거나, 타임라인의 이름을 눌러도 됩니다.
보정은 원본 추적 결과를 건드리지 않는 기록으로 쌓이므로 ⌘Z 로 되돌릴 수 있습니다.
**다시 분석하면 보정 기록은 초기화됩니다.**

### 9. 여러 클립을 하나로

1. 영상을 여러 개 추가
2. `분석 ▾` → **모든 클립 분석** (⌘⌥R) — 일부가 실패해도 나머지는 계속 진행
3. 클립 목록에서 클립을 골라 각각 편집
4. `내보내기 ▾` → **전체 이어붙이기** (⌘⇧E)

- 해상도 · fps가 달라도 됩니다. 가장 큰 클립 규격에 맞추고, 작은 클립은 비율을 유지한 채 여백을 넣습니다.
- 분석 없이 원본만 이을 때는 **분석 없이 그냥 이어붙이기** (⌘⌥E).
- 작업 중에는 상태 표시줄 오른쪽 **×** 로 분석 · 내보내기를 취소할 수 있습니다.

### 10. 저장 · 되돌리기

- **⌘S** 로 프로젝트(`.fbproj`)를 저장합니다. 모든 클립의 추적 결과와 편집 내용이 들어갑니다.
  원본 영상은 들어가지 않으므로 **영상 파일을 옮기거나 지우지 마세요**(옮겼다면 클립 목록에 빨간 점이 뜹니다).
- **⌘Z / ⌘⇧Z**: 최대 80단계. 되돌리기는 클립마다 따로 유지됩니다.
- 속성 패널 맨 아래 `모든 작업 초기화` 는 편집 내용만 지웁니다(영상과 분석 결과는 유지, ⌘Z 가능).

| ⌘O / ⌘N | 영상 추가 / 새 세션 |

## 문제 해결

<details>
<summary><b><code>Could not find the Qt platform plugin "cocoa"</code> 로 실행되지 않음</b></summary>

가상환경이 Anaconda Python으로 만들어졌거나, 가상환경 폴더에 macOS 숨김 플래그가 걸린 경우입니다.
앱이 두 경우 모두 감지해 해결 명령을 출력합니다. 보통은 아래로 해결됩니다.

```bash
./run.sh --setup
```

conda가 활성화된 셸이라면 `conda deactivate` 후 실행하거나, `FBEDIT_PYTHON` 으로 python.org Python을 지정하세요.
</details>

<details>
<summary><b>"확인되지 않은 개발자" · 권한 경고</b></summary>

`run.sh` 는 서명된 앱이 아니라 스크립트이므로 터미널에서 실행합니다. `permission denied` 면 `chmod +x run.sh`.
</details>

<details>
<summary><b>앱이 아무 반응 없이 멈춤</b></summary>

프로젝트나 영상이 iCloud 동기화 폴더에 있고 파일이 클라우드로 내보내졌을 수 있습니다.
Finder에서 해당 파일의 구름 아이콘을 눌러 내려받거나, 작업 폴더를 iCloud 밖으로 옮기세요.
</details>

<details>
<summary><b>첫 분석이 오래 걸림 / 실패함</b></summary>

첫 분석 때 모델 가중치를 내려받습니다(인터넷 필요). 이후에는 오프라인에서도 동작합니다.
Intel Mac은 GPU 가속이 없어 매우 느립니다 — 분석 구간을 줄이고 `빠름` 프리셋을 쓰세요.
</details>

<details>
<summary><b>팀이 잘 안 갈림</b></summary>

두 팀 유니폼 색이 비슷하거나(예: 남색 vs 검정) 화면이 어두우면 한 팀으로 봅니다.
선수 속성의 `팀 A / 팀 B / 기타` 로 직접 지정하세요.
</details>

<details>
<summary><b>업데이트 후 오류</b></summary>

`./run.sh --setup` 으로 의존성을 다시 설치하세요. 오류 창의 내용을 Issue에 붙여 주시면 도움이 됩니다.
</details>
